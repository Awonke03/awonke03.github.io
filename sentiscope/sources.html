Data & model sources

Non-commercial portfolio application. Default feedback is authored illustrative text, not actual customer records. No raw training comments are redistributed.

Sentiment in all languages: Multilingual DistilBERT (ONNX). A single shared sentiment classifier processes single comments and uploaded feedback; accuracy varies by language and has not been validated for every South African language.

English emotions: GoEmotions (Demszky et al. 2020, Apache 2.0). Multilabel classifiers trained on the provided splits.

Browser Transformers: DistilBERT multilingual sentiment and multilingual MiniLM embeddings. First use downloads model files; performance varies by language and device. Language labels are optional user-supplied metadata, not inferred. English-only emotion and topic features require English metadata. Mixed sentiment and topic labels are explicitly heuristic. Not intended for consequential automated decisions.
