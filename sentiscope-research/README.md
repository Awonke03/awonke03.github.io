# SentiScope

Static application with genuine client-side inference. Serve the repo root using `python -m http.server 8765` and open /sentiscope/. Run training using the pinned dependencies in the GitHub Actions workflow. No API key required. Model weights are published after parity and browser tests. Optional Transformers download quantized ONNX files into the browser. They require memory, network and time on first use. No text is intentionally sent to an inference API. Third-party scripts and model hosts receive normal download requests.

The default feedback is authored illustrative content, not actual customer data. Do not upload private customer information. Supported compact language classifiers: English and Xitsonga (Mozambique source), not all South African languages. English topic taxonomy and clause-based mixed sentiment are heuristics. Emotion labels are multi-label; scores are uncalibrated. No automatic language ID, NER, urgency or fine-tuned multi-task Transformer is claimed. Excel first worksheet, CSV and plain-text imports; 2 MB/2,000 rows. Transformer semantic search limited to 200 comments. Model results in report.json and notebook, not app screens. The research notebook reads the generated report; it is not pre-executed.
