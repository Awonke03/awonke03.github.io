# Semantica

Static application with genuine client-side inference. Serve the repo root using `python -m http.server 8765` and open /sentiscope/. Run training using the pinned dependencies in the GitHub Actions workflow. No API key required. Model weights are published after parity and browser tests. Multilingual DistilBERT is the sole active sentiment classifier for individual and bulk inputs. Transformers download quantized ONNX files into the browser. They require memory, network and time on first use. No text is intentionally sent to an inference API. Third-party scripts and model hosts receive normal download requests.

The default feedback is authored illustrative content, not actual customer data. Do not upload private customer information. The older compact sentiment models and their training report are retained as historical experiments only and are not used for predictions. Language metadata is optional and not automatically inferred. Multilingual sentiment quality has not been validated for every language. English emotion classification is separate. English topic taxonomy and clause-based mixed sentiment are heuristics. Emotion labels are multi-label; scores are uncalibrated. No automatic language ID, NER, urgency or fine-tuned multi-task Transformer is claimed. Excel first worksheet, CSV and plain-text imports; 2 MB/2,000 rows. Transformer semantic search limited to 200 comments. Model results in report.json and notebook, not app screens. The research notebook reads the generated report; it is not pre-executed.

## Web intelligence and explanations
GDELT DOC API live headline search (up to 30 deduplicated titles, 7/30/90 days, no API key). Search queries are sent to GDELT; inference stays in the browser. Provider availability and language coverage vary. No full article, social media or review scraping. The overview dataset changes only after successful analysis. Word explanations use actual classifier score changes after removing each of the first 24 word segments, for the leading class; mixed sentiment is a separate rule. Sources and dates are exported with web results.
